# 相册类别管理 · 详细设计

模块为相册管理。管理员登录后进入类别管理后台，查看类别并执行新增、修改和删除。设计依据为[相册类别管理需求](../../../需求分析/03_完整需求分析报告.md#相册类别管理)与[公共设计约定](../../01_公共设计约定.md)。

## 1. 接口与对象

| 接口 | 输入 | 成功结果 |
| --- | --- | --- |
| `GET /api/categories` | 当前会话 | `200`，返回按标识正序排列的 `CategoryView` 列表 |
| `POST /api/categories` | JSON 字段 `name` | `201 CategoryView` |
| `PUT /api/categories/{category_id}` | 类别标识与 `name` | `200 CategoryView` |
| `DELETE /api/categories/{category_id}` | 类别标识 | `204` |

| 对象 | 职责 |
| --- | --- |
| Vue 类别管理页 | 显示类别列表，收集名称，展示维护结果并在成功后刷新列表。 |
| FastAPI 类别路由、`CategoryService` | 解析请求，使用 `list_categories()` 查询类别，按操作调用 `create(actor, data)`、`update(actor, category_id, data)` 或 `delete(actor, category_id)`。服务对写入操作检查管理员角色。 |
| `Category`、`Album` | 分别记录类别及相册对类别的引用，支撑重名与占用判断。 |

## 2. 调用流程

管理员打开后台，页面读取类别列表。管理员每次选择下列一项操作，服务检查角色后执行对应分支。

- **新增**。服务去除名称首尾空白，校验 1–50 字符并检查名称唯一。校验通过后在事务内写入新类别，提交后返回 `201`。
- **修改**。服务加载指定类别，按相同规则校验名称，查重时排除当前类别。保留类别标识，事务提交后返回 `200`。
- **删除**。服务加载指定类别，查询是否有相册引用。无引用时在事务内删除并提交，返回 `204`。相册新增引用与删除并发时，由 `albums.category_id` 外键保证引用有效。

页面在收到所选操作的成功结果后刷新类别列表。相册表单下次加载类别时显示更新后的选项。

## 3. 异常处理

| 情况 | 返回与界面行为 |
| --- | --- |
| 名称为空或过长 | `422 VALIDATION_ERROR`，定位 `name` 并保留输入。 |
| 名称与其他类别重复 | `409 CATEGORY_NAME_TAKEN`，显示重名提示。并发写入触发唯一约束时回滚并返回同一错误。 |
| 目标类别不存在 | `404 CATEGORY_NOT_FOUND`，提示类别已不可用并刷新列表。 |
| 类别仍被相册引用 | `409 CATEGORY_IN_USE`，提示“该类别下存在相册，不能删除”，保留类别。删除时触发外键约束也返回此错误。 |

## 4. 结果检查

- 类别修改后，引用它的相册仍指向同一类别标识，并显示更新后的名称。
- 有相册引用的类别删除失败。无引用的类别删除成功，随后从相册表单选项中消失。
- 普通用户可读取类别列表，向同一路径发起新增、修改或删除请求时被拒绝。
