# 上传图片 · 详细设计

模块为照片管理。已登录的普通用户从本人相册发起单张图片上传。设计依据为[上传图片需求](../../../需求分析/03_完整需求分析报告.md#上传图片)与[公共设计约定](../../01_公共设计约定.md)。

## 1. 接口与对象

| 接口 | 输入 | 成功结果 |
| --- | --- | --- |
| `GET /api/albums/{album_id}?scope=mine` | 相册标识 | `200 AlbumView`，确认相册归属后显示上传入口 |
| `POST /api/albums/{album_id}/photos` | `multipart/form-data` 中的单个 `file` 和 UUID 格式的 `upload_id` | `201 PhotoView`，重试命中已提交记录时返回 `200 PhotoView` |

| 对象 | 职责 |
| --- | --- |
| Vue 相册页 | 展示文件选择入口，提交图片并展示结果，成功后将新照片加入当前相册。 |
| FastAPI 照片路由 | 调用 `PhotoService.upload(actor, album_id, file, upload_id)`，按返回的照片和是否新建生成 `PhotoView` 及相应状态码。 |
| `PhotoService`、`AlbumAccessPolicy` | 检查角色和相册归属，校验图片，协调文件处理和数据库事务。 |
| `LocalPhotoStorage`、`Photo` | 存储对象保存或清理图片文件，照片实体保存文件路径和业务元数据。 |

## 2. 调用流程

1. 页面通过 `scope=mine` 读取相册。校验通过并选取图片后，页面为此次选择生成 `upload_id`，连同文件提交。重试使用原标识和原文件，重新选图生成新标识。收到上传请求后，路由检查普通用户角色，服务调用 `require_owned(actor, album_id)` 重新确认归属。
2. 服务检查原图字节数为 1–10,000,000，解码识别 JPEG、PNG 或 GIF。按识别结果确定原图扩展名及 `media_type`。
3. 服务为本次尝试生成独立 `file_key`。在数据库事务中，带上两条预定路径、上传时间和元数据插入 `photos`，用 `ON CONFLICT (album_id, uploader_id, upload_id) DO NOTHING RETURNING id` 预留记录。若同键请求正在执行，唯一索引会等待其事务结束。若已提交，在默认的读已提交隔离级别下用下一条查询读取既有照片，返回 `200`。新插入的记录在事务提交后才可见。
4. 获得预留记录后写入文件。在 `uploads/` 下使用相对目录 `albums/{album_id}/{file_key}/`，分别保存 `original.<ext>` 和 `thumbnail.png`。原图保留上传字节，缩略图等比缩放至最长边不超过 320 像素，GIF 取首帧。
5. 两个文件写入并关闭成功后，提交照片记录并返回 `201 PhotoView`。
6. 页面按返回的照片标识更新缩略图列表，同一照片显示一次。

## 3. 异常处理

| 情况 | 返回与界面行为 |
| --- | --- |
| 相册不存在或不属于当前用户 | `404 ALBUM_UNAVAILABLE`，提示“相册不存在或无权上传”，返回相册列表。 |
| 缺少文件，或上传标识缺失、格式无效 | `422 VALIDATION_ERROR`，`error.field` 分别为 `file` 或 `upload_id`。 |
| 文件超过大小上限 | `413 IMAGE_TOO_LARGE`，提示重新选择不超过 10 MB 的图片。 |
| 格式不支持、内容为空或无法解码 | `422 INVALID_IMAGE`，提示具体原因，回到选择状态。 |
| 文件处理失败或事务已确认回滚 | `500 UPLOAD_FAILED`。服务回滚并清理本次 `file_key` 对应的文件。 |
| 提交结果未知或响应中断 | 提交结果未知时返回 `503 UPLOAD_STATUS_UNKNOWN` 并保留文件。客户端未收到响应时同样按原 `upload_id` 重试。服务按步骤 3 判定此前是否已提交。 |

服务进程中断后，由[系统验收与恢复设计](../../03_系统验收与恢复设计.md)中的启动核对处理遗留文件。

## 4. 结果检查

- 上传成功后，一个照片记录对应一份原图和一份 PNG 缩略图，上传者为当前用户。
- 文件正好为 10,000,000 字节且格式合规时通过大小检查，超出一字节时返回 `413`。
- 缩略图生成失败或事务确认回滚后，无可见记录，清理范围限本次文件。模拟落盘后、提交前进程中断，重启核对能识别无记录的目录。
- 模拟提交后响应丢失，按原标识重试应返回同一照片，库中只有一条记录，两份文件均可读取。
