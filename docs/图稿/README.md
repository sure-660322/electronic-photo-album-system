# 图稿目录说明

本目录放**报告正文用图**（第 1、2 章）的 `.drawio` 源文件与 PNG。

- `图2-1_系统体系结构图`、`图2-2_功能框架图`：由 `tools/gen_drawio.py` 生成。
  已按 [docs/绘图规范.md](../绘图规范.md) v2.1 重出，PNG 与 `.drawio` 均已同步，核对记录见 [返修检查记录](返修检查记录.md)。报告沿用原编号；后续改图走脚本，不手改 XML。
- `教学演示/`：早期教学示意图，旧版黑白风格，**不入报告**，不参与返修。
- 成员交付的用例图、活动图、类模型图、协作图不放在本目录，统一在
  `docs/交付/<编号-模块-姓名>/images/`；图编号由组长整合排版时统一添加。

导出与后处理的命令、字号预算见 [tools/README.md](../../tools/README.md)。
