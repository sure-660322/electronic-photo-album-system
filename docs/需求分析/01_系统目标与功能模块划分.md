## 1. 系统目标（报告正文草稿）

本系统旨在开发一个基于 Web 的电子相册系统，采用 B/S（浏览器/服务器）体系结构和 MVC 设计模式，帮助用户对照片进行分类管理，并与他人分享和交流，解决电脑中照片数量多、不易查找和分享的问题。

系统面向两类用户：普通用户和管理员。普通用户可以注册、登录系统；登录后可以创建相册（相册分为公开和私有，私有相册仅本人可见，该属性可在修改相册时变更）并上传照片；可以浏览其他用户公开的相册和照片，并对照片发表评论、删除自己的评论。管理员登录后可以对系统的相册类别进行维护管理。

本系统仅针对照片管理，不支持视频；不包含点赞、关注、信息流等社交功能。

## 2. 功能模块划分

| 模块 | 包含用例 | 说明 |
|------|----------|------|
| 账户管理 | 用户注册、用户登录 | 管理员登录复用用户登录，管理员是特殊用户，不单独画用例 |
| 相册管理 | 创建相册、修改相册、相册类别管理 | 相册的名称、类别、公开/私有属性；类别由管理员维护 |
| 照片管理 | 上传图片、浏览照片 | 上传格式/大小校验；浏览含他人公开相册 |
| 评论管理 | 对照片评论 | 发表评论、删除自己的评论，作为该用例的扩展流程 |

### 关键约定（画图前全员对齐）

1. "分享"= 所有登录用户可浏览他人**公开**相册，无好友机制。
2. 相册分公开/私有，创建时选择，修改相册时可变更。
3. 评论：可对任何可见（公开）照片评论；可删除自己的评论（写进用例扩展流程）。
4. 管理员登录复用用户登录用例。
5. 不支持视频，不做点赞/关注/信息流。
